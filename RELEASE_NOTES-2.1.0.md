# РИТМ 2.1.0

## Ребрендинг
Продукт переименован из Schedule Studio в **РИТМ**. Новый подзаголовок: **Профессиональная система управления расписанием**.

## Что изменено
- новое имя приложения и Windows-продукта: `РИТМ`;
- новый `appId`: `ru.ritm.schedule`;
- новый нейтральный логотип и иконка без привязки к конкретной организации;
- обновлены заголовки, боковая панель и служебные надписи;
- JSON/CSV/HTML/PDF экспорт использует имя РИТМ;
- опубликованные A4-представления используют бренд РИТМ;
- сохранена совместимость со старым хранилищем и локальными ключами Schedule Studio;
- историческая папка `%APPDATA%\Schedule Studio` намеренно сохранена, чтобы обновление не потеряло существующие данные.

## Основа релиза
Внутри сохранены исправления persistence 2.0.2 и A4-печатных представлений 2.0.3.
