# Графикс 2.2.1

## Исправления и UI
- Редактор печатной страницы: добавлена точная настройка ширины каждого столбца в мм.
- Редактор печатной страницы: добавлена точная настройка высоты каждой строки в мм.
- Размеры строк и столбцов сохраняются в настройках печати.
- Сохранено удаление выбранных строк и столбцов без изменения исходного расписания.
- Панель редактора размеров переработана в компактный двухколоночный менеджер.
- Главная страница: календарь и часы объединены в один лаконичный блок.
- Публичное расписание: предпросмотр отделён от генерации Tilda-кода и показывает понятное состояние при отсутствии занятий.
- Tilda-код: исправлена генерация Base64 для больших сжатых данных без опасного spread по всему массиву байтов.
- Tilda-код: добавлен безопасный маркер сжатия; при отсутствии DecompressionStream выводится понятное сообщение вместо пустого блока.
- Ошибки формирования Tilda-кода теперь отображаются в статусе, а не приводят к молчаливому отсутствию кода.
- Обновлена версия приложения до 2.2.1.

## Иконка
Фирменная иконка Графикс находится в `assets/icon.ico` и подключена к Windows-сборке через `package.json`.
Исходный PNG-вариант: `assets/icon.png`.
