# Графикс 2.2.8

## Изменения

- Старый встроенный логотип `assets/logo.png` удалён из приложения. В интерфейсе приложения, фавиконе и печатном представлении используется новый фирменный знак из `assets/icon.png`, соответствующий значку приложения на рабочем столе Windows.
- Логотип организации по-прежнему можно загрузить в настройках; если пользовательский логотип не задан, используется новый фирменный знак приложения.
- В блоке «Так будет выглядеть расписание на сайте» удалено горизонтальное переключение дней «Пн / Вт / Ср / …».
- В готовом коде публикации Tilda также убрана отдельная горизонтальная лента дней; выбор дня остаётся через компактный фильтр «День».
- Фильтры по группам и поиск сохранены.

## Проверки

После изменений выполнены статические и runtime-проверки проекта.
