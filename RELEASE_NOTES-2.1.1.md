# РИТМ 2.1.1 — улучшенный A4-печать

## Что изменено

- Переработан вид раздела «Печатные представления»: теперь печатная форма строится как компактная A4-матрица.
- Для «По дню недели» используется матрица «время × кабинеты/ресурсы».
- Для «По группе», «По педагогу» и общего недельного вида используется матрица «время × дни недели».
- Ориентация: A4, альбомная.
- Для обычного расписания весь выбранный вид строится на одной странице A4; плотность строки автоматически подстраивается под количество временных слотов.
- Сетка стала тоньше, заголовки крупнее, внутренние подписи компактнее, а содержимое ячеек структурировано по строкам: занятие, педагог, группа, кабинет.
- Исправлена ошибка в `downloadSelectedReportA4PDF()`, где `type` и `value` могли быть не определены.
- В «Редактор печатной страницы» добавлена явная панель управления удалением выбранных строк и столбцов.
- Столбцы теперь удаляются физически из редакторского набора и могут быть восстановлены.
- Для строк добавлены выбор всех/снять выбор и подтверждение удаления всех строк.
- Предусмотрено сохранение параметров печати через существующий persistence-механизм.
