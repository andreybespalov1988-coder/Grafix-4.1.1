# Графикс 3.1.0 — Scheduling Engine

## Главное
- Новое модульное ядро Scheduling Engine.
- Hard/soft constraints с приоритетами.
- Три стратегии генерации расписания.
- Центр конфликтов и объяснение невозможности.
- Закреплённые занятия сохраняются при генерации.
- Многонедельная модель учебного периода.
- Модуль замен педагогов.
- XLSX import wizard и XLSX export.
- Расширенная аналитика.
- Автоматическая попытка исправления конфликтов только после подтверждения.

## Совместимость
Старые данные 3.0.0 мигрируются через существующий normalize/storage pipeline.

## Ограничения
AI, серверная совместная работа и live Tilda остаются отдельными интеграционными этапами.
