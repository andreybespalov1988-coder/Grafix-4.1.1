# Графикс 2.2.3 — dashboard, publication and teacher availability

- Главная: компактный календарь с видом месяца, навигацией по месяцам и отметками дней с занятиями.
- Главная: часы и календарь перенесены перед компактным блоком «Контроль качества»; контроль качества расположен справа.
- Публикация на сайте: генерация Tilda-кода больше не зависит от успешности предпросмотра; код формируется даже при пустом расписании, а ошибки не очищают поле молча.
- Педагоги: добавлены ограничения недоступности — целый день или конкретный интервал времени; можно добавлять несколько периодов.
- Ограничения педагогов учитываются в контроле конфликтов, отчёте ограничений и поиске свободных позиций.
- Windows icon: используется выбранный логотип Графикс из `assets/icon.png`, а `assets/icon.ico` подготовлен для разных размеров Windows.
