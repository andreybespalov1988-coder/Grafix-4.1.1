# Графикс 2.2.2 — production hardening

## Исправления
- Добавлена блокировка второго экземпляра приложения, чтобы параллельные окна не перезаписывали общую базу расписания.
- Для Windows задан стабильный AppUserModelId `ru.grafiks.schedule`.
- Навигация Electron ограничена собственным `index.html`; внешние и неожиданные file:// переходы блокируются.
- Запрещены неожиданные permission-запросы renderer-процесса.
- Добавлено ограничение размера импортируемого файла — 50 МБ.
- Усилено экранирование данных конфликтов перед вставкой в DOM.
- Повторно проверены сохранение, восстановление, A4, UI, Tilda/public runtime и редактор размеров печатной страницы.

## Release status
Исходный проект прошёл доступный автоматический QA-набор. Нативная Windows-сборка требует доступных пакетов Electron/electron-builder и должна быть выполнена в среде с npm registry.
