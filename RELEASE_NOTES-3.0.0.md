# Графикс 3.0.0

## Главное
- Новый локальный движок автоматического составления расписания.
- Жёсткие ограничения: пересечения ресурсов, доступность педагога, рабочие часы, дневные лимиты.
- Мягкая оптимизация компактности расписания.
- Несколько вариантов автосоставления с объяснением незаполненных занятий.
- Структурированные ссылки teacherId / groupId / roomId с сохранением обратной совместимости со старыми текстовыми полями.
- Правила расписания и аналитика нагрузки.
- История изменений.
- Новый раздел «Аналитика».
- Сохранены локальное хранение, печать, Tilda, импорт/экспорт и существующий редактор расписания.

## Ограничения 3.0.0
- XLSX без внешнего сервиса пока не добавлялся: текущий обмен остаётся CSV/JSON/XML/HTML.
- AI-провайдер не подключён: основное автосоставление работает полностью локально и не требует API-ключа.
- Совместная работа/роли/живая облачная публикация требуют серверной инфраструктуры и не включены в local-first сборку.
