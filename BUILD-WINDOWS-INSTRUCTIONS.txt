ГРАФИКС 2.2.4 — СБОРКА WINDOWS

1. Установите Node.js LTS (20+).
2. Распакуйте проект в любую папку.
3. Откройте CMD или PowerShell в папке, где находится package.json.
4. Запустите build-windows.bat.
5. Скрипт установит зависимости, выполнит проверки, удалит старую папку release и соберёт NSIS Installer + Portable.
6. Готовые файлы появятся в release.

Перед выпуском проверьте:
- запуск установленной программы;
- создание/изменение организации;
- загрузку логотипа;
- создание расписания;
- сохранение и повторный запуск;
- импорт aSc XML/HTML/CSV и текстового .roz;
- редактор печати;
- PDF;
- экспорт JSON/CSV;
- публикацию HTML/Tilda.

Если .roz — закрытый бинарный файл aSc, используйте экспорт из aSc в XML/HTML/CSV.


### Проверка persistence на двух реальных Electron-процессах
После `npm install` запустите `electron_persistence_test.bat`. Тест создаёт временный Electron userData, запускает Графикс для записи данных и затем запускает второй процесс для чтения. В конце он проверяет организацию, филиал, активный филиал, занятие и завершает кодом 0 только при полном восстановлении.


Бренд: Графикс — Профессиональная система управления расписанием.
